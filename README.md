# 🎬 YouTube Downloader

A web-based YouTube video downloader with Cloudinary CDN integration.

## Features
- Download YouTube videos in multiple qualities (Best, 1080p, 720p, etc.)
- Extract audio as MP3
- Real-time progress bar
- Cloudinary CDN for fast downloads
- Clean, responsive UI

## Tech Stack
- Flask (Python web framework)
- yt-dlp (YouTube downloader)
- Cloudinary (CDN storage)
- HTML/CSS/JavaScript

## Local Development
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python app.py`
4. Open: `http://localhost:5000`

## Deployment
Deployed on Render.com with Cloudinary CDN.
